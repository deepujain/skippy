# ts-mono contribution queue policy

Target healthy open contributions: 5 (Skippy default)
Repository or contributor maximum: unknown; no lower public policy found on 2026-09-01
Configured by: user request and live-policy scan
Refresh trigger: before every replenishment run and whenever repository policy changes

An active CI run makes only that PR temporarily unhealthy; it does not block
independent, qualified contributions from filling other concurrent slots.

Read the shared references/contribution-queues.md policy before configuring
or acting on a target.
