Contribution Queue

## Done means

- [x] Every authored open PR has current CI, review, signature, and base-state evidence.
- [x] Every contributor-actionable conflict, failure, or review finding is fixed and pushed.
- [x] Departed PRs are reconciled and the queue contains exactly five qualified open PRs, or every missing slot has a source-backed blocker.
- [x] The final receipt is based on an author-scoped open query and exact-head comparison against `main` after the last remote mutation.

## Constraints to preserve

- [x] Preserve each PR's intended behavior and current upstream security boundaries during rebases.
- [x] Use only signed, DCO-compliant commits and exact force-with-lease pushes to the fork.
- [x] Do not create a sixth PR or duplicate another contributor's work.
- [x] Report maintainer-only workflow and credential gates as blocked, never green.

## Task list

- [x] Read the Skippy decision system, contribution-queue playbook, shared contribution protocol, graph control, and NemoClaw skill and queue policy.
- [x] Maintain: reconcile departed PRs; inspect every open PR's reviews, checks, signatures, and base state; repair and push actionable work.
- [x] Learn: scan current outcomes and a bounded peer sample; update the narrowest durable rule only if new evidence warrants it.
- [x] Replenish: compare the author-scoped open count with the live cap; fill each missing slot through the full collision-screened recipe.
- [x] Verify: run proportional focused and broad checks for every changed head and inspect each final diff.
- [x] Delivery refresh: after the last remote mutation, re-query the authored-open set, current base, exact heads, signatures, CI, reviews, and publication state.
- [ ] Deliver the required one-row-per-PR action table plus Maintain, Action, and Self Learning summary.
