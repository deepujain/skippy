# Security Hardening Playbook

1. Identify the trust boundary, attacker capability, protected asset, and
   recovery path.
2. Bind the behavior to exact identities and authoritative configuration.
3. Fail closed for malformed or unknown inputs while proving a valid path
   remains usable.
4. Test mutations for atomicity, precedence, permissions, and cleanup.
5. Ask for focused review when the change affects credentials, policy,
   containment, provenance, or external execution.
