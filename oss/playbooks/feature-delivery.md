# Feature Delivery Playbook

1. Define user-visible behavior, non-goals, compatibility expectations, and
   measurable acceptance criteria.
2. Find the production owner and design a thin integration boundary.
3. Implement in small, reviewable increments without speculative abstraction.
4. Exercise the public path, error path, and persisted or external contract
   when applicable.
5. Validate documentation, migration, and operational impact before delivery.
