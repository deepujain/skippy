# Bug Fix Playbook

1. Capture the failing contract and a minimal reproduction.
2. Locate the owning boundary and existing coverage.
3. Screen issues, PRs, commits, and hot-file overlap.
4. Implement the smallest correction and a regression proving the old failure
   plus a representative valid path.
5. Run focused validation, then the repository's proportional broader gate.
6. Deliver with before/after evidence and any environment limits.
